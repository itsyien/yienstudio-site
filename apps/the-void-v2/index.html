The Void: Satisfying file tool

The Void is a Windows desktop file tool that turns common tasks into a simple drag-and-drop. Drop files into its animated black hole to send them to the Recycle Bin, move them into an archive, copy them to an inbox, or compress them into a ZIP. It includes operation history, undo, customizable destinations, and runs as a standalone .exe — no .NET required.

Platform: Windows

How to use

  • Download The Void for Windows and run the .exe.
  • Keep The Void on your desktop or pin it somewhere easy to reach.
  • Drag files or folders into the black hole.
  • Choose recycle, archive, inbox, or ZIP — undo from history if you change your mind.

Features

  • Animated black-hole drag-and-drop
  • Recycle Bin, archive, inbox, and ZIP actions
  • Operation history with undo
  • Customizable destinations
  • Standalone Windows app — no .NET runtime
