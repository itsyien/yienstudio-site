Latch

Latch is a no-admin Windows utility that lets you give completed downloads a safe lifetime at the moment they arrive. A quiet flyout above the taskbar offers a recommended lifetime with one click; the timeline snaps to 1 hour, Tonight, 3 days, or 7 days. Nearby downloads batch into one prompt, expiry moves files to a recoverable Expired folder (no automatic permanent delete in V1), and closing or ignoring a prompt never changes the file.

Platform: Windows

How to use

  • Run Latch and let it watch your Downloads folder in the background.
  • When a download finishes, choose a lifetime from the flyout timeline — or Keep to leave the file alone.
  • Manage the queue from the main window: restore expired files, extend lifetimes, or Remove from Latch.
  • Optionally enable Explorer shortcuts and Send to for manual latching without admin rights.

Features

  • Taskbar flyout with one-click recommended lifetime
  • Interactive four-stop timeline: 1 hour, Tonight, 3 days, 7 days
  • Quiet batching of nearby download completions
  • Selective batch latching — unselected files stay untouched
  • Safe expiry to a recoverable Expired folder
  • Undo-friendly restore, extend, and Remove from Latch
  • No-admin tray app with optional Explorer / Send to shortcuts
